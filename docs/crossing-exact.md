# 精确交叉数层与规律性放置（WS2）——数学定义与正确性论证

> Engineering doc, maintained in Chinese — English overview: README.md

本文件给出 `stdraw/crossing_exact.py`、`stdraw/regularity.py`、
`stdraw/placement.py` 的完整数学框架。所有「proven-optimal」主张都以本文
定义的模型类为准；证书措辞与本文同步，绝不虚称。

## 0. 口径

- 图取简单无向视图：去自环、保留平行边（good drawing 下平行边互不相交，
  可并列绘制；平行边各自独立计入交叉）。
- **good drawing 口径**：相邻边（共享端点）不交叉；任意两边至多交叉一次；
  无三边共一点。任何画法都可在此口径内扰动且不增加交叉数，故
  cr(G) = good-drawing 意义下的最少交叉数。
- cr 可加性引理（本文多次使用）：画在不相交圆盘内的子图互不交叉。

## 1. 安全缩减（每条都有 cr 保持证明）

| 缩减 | 证明 |
|---|---|
| 删自环 | 自环在端点附近画小圈，可避开一切其他边 → 交叉贡献 0 |
| 连通分量分解 | 各分量画在不相交圆盘内 → cr(G) = Σ cr(C_i)（≥ 方向：不同分量边对的交叉在分别计数后不复存在，而最优画法每个分量的交叉数不低于其自身 cr） |
| 迭代删度 ≤1 顶点 | 度 0 平凡；度 1 顶点 v(邻 u)：先画 G−v 最优，再把 v 放进 u 的任一关联面内、短线连 vu → 0 新增交叉。两方向合并得 cr(G)=cr(G−v) |
| 桥分解（Tarjan） | 桥 uv：u 侧画完后把 v 侧整块按比例缩小放进 u 的关联面内、桥贴边连接 → 0 交叉。cr(G)=Σ cr(2-边-连通块) |

缩减后核族满足 **cr(G) = Σ cr(cores)**，是后续一切论证的输入。

## 2. 分解定理（插入式精确化的基础）

**定理 A.** 设 U ⊆ G 为可平面子图，Π 为 U 的一个平面嵌入。把 F = E\U
**同时**最优插入 Π（每条 e∈F 画成与 U 边至多逐次相交的简单弧，弧间可交叉）
得到的最少交叉数记为 ins(F, Π)，则

> cr(G) = min over (U 可平面子图, Π ∈ Emb(U)) ins(E\U, Π)。

**证明.**（≤）任一插入方案本身就是 G 的合法画法，故各项 ≥ cr(G)，min ≥ cr。
（≥）取 G 的最优画法 D（交叉数 cr(G)，good drawing）。令 U = D 中未被交叉的
边集（D|_U 无交叉 → U 可平面），Π = U 在 D 中的嵌入。逐条考察 F = E\U 的边 e：
- e 与 U 的边 g 的每个交点 p：局部上 e 从 g 一侧的面穿到另一侧的面，
  恰为「经 g 的侧转移」一次；e 依其在 D 中交点的顺序得到 Π 的对偶图上
  一条 source→sink 路径；
- e 与 e′（同属 F）的交点位于 Π(U) 的某个公共面内部。
故 D 恰好分解为 (U, Π) 的一个插入方案，其交叉数 = ins(F, Π) = cr(G)。
∎

## 3. 枚举覆盖与提前剪枝

**定理 B（见证子集收缩）.** 对任意 F 与其插入方案代价 c，令 F_x ⊆ F 为其中
实际发生交叉的边。则 |F_x| ≤ 2c（每个交叉至多涉及两条 F 边）且
ins(F_x, Π|...) ≤ c（删除未交叉边不改变方案）。故：

> min over 所有 F ins(F, Π_F) 在某个 |F| ≤ 2·cr 的「全交叉」F 上取到。

推论：设当前最好上界为 UB。任何代价 < UB 的 F 都有 |F| ≤ 2(UB−1) 的见证。
因此只需枚举 |F| ≤ 2·UB−2 的候选；且 UB 在枚举中改善时，枚举上界可动态收缩
（代码中 `k > 2*best_ub-2 → break`）。另一剪枝：ins ≥ ⌈|F|/2⌉ 的平凡下界
淘汰 ⌈k/2⌉ ≥ UB 的整层。

**嵌入枚举**：连通图的平面嵌入 ↔ 满足欧拉判据（面数 = m−n+2）的旋转系。
代码逐顶点回溯循环序：每顶点固定首元素折叠旋转等价；首个顶点额外要求
第二元素 < 末元素折叠全局镜像（镜像的插入代价相同，折叠不损完备性）；
叶上用欧拉判据验证。枚举设确定性计数上限 `rotation_cap`，超限如实把
coverage 标为 partial（见 §5）。

## 4. 插入子问题的精确解：CP-SAT 提议 + 平面化 oracle 裁决

对固定 (U, Π)：把 Π 的每个面用虚弦三角化（弧穿虚弦不计交叉；大面中的画法
与三角化后逐三角形行走的画法一一对应，虚弦交叉擦除即还原，代价不变）。
以三角形为节点、面-侧为边构造对偶图。

**桥/割点口袋拆分**：U 来自贪心可平面子图（初始 UB 路径不要求 2-连通），
桥与割点使同一几何面的边界游走经过同一顶点多次（桥边两侧 dart 落入同一
面游走）。此类游走直接扇形三角化不成立（三角形重叠、侧只邻一个三角形——
修复前在此断言崩溃）。处理：在重复顶点处把游走递归拆成简单圈
（内圈 = 该次经过围出的口袋，外圈 = 去掉口袋后的余边界；两圈的相邻顶点对
都是原游走的 dart，仍是合法闭游走），再逐圈扇形三角化，虚弦面 id 按拆分后
的圈编号。拆分后的三角形复形仍是球面的合法胞腔分解，ILP 路由语义不变
（弧离开口袋必须穿真边——几何上正确）；正确性仍由 oracle 保证，成本只是
该嵌入下插入问题的精确值。B&B 枚举侧的候选早已用 2-连通过滤，不受影响。

**ILP（超集建模）**：每条 e∈F：
- source/sink 三角形选择变量（source ∈ 含尾端点的三角形，sink ∈ 含头端点的；
  端点不在 U 任何面上时放开为任意三角形——该顶点悬浮于面内）；
- 每侧方向流变量 f（0/1），f₀+f₁ = u；三角形上流量守恒 = source−sink；
  → f 的支撑 = 一条 source→sink 路径（外加若干可剥离的独立环）；
- 每侧 u ≤ 1（good drawing 口径：同边对至多交叉一次）；
- 相邻边侧强制 u = 0；
- c_{e,e′} ∈ {0,1}（互交叉），且 c ≤ Σ_T z_T（z_T ≤ 「两弧都经过 T」）：
  互交叉必须发生在公共三角形内。

**裁决 oracle**：由解 (路径, c) 构造平面化抽象图 H：U 全部加入；每个
(弧, 真边) 交叉点成为细分顶点 X（该边被细分为两段、弧路径经过 X；同一边
可被多条弧依次细分）；每个互交叉 c_{e,e′} 成为公共顶点 X，两条弧路径都
经过 X（按各自路径序插入）。则：

> **定理 C.** (路径, c) 可实现为 good drawing ⟺ H 可平面。

**证明.**（⇒）实现画法沿交叉点切开即 H 的平面画法。（⇐）取 H 的平面画法。
G 的每条边对应 H 中一条顶点序列（原始端点与若干 X）；把每个 X 的 ε-邻域内
重画：X 处恰有四条半边（两段来自参与交叉的边/弧），在 ε-盘内改画为一对
横穿的曲线段，使规定的边对在该处恰好横交一次，且盘内不产生其他交点
（四个接触点的两种配对总可实现横穿）。弧保持简单、只与其规定交叉对象相交。
得到 G 的画法，其交叉集 ⊆ 规定交叉集（个别规定的交叉若被画成相切，
扰动后至多消失，不会新增）。∎

**推论（精确性）.** min over 模型可行解（经 oracle 放行）的规定代价 = ins(F, Π)：
- 每个放行解给出代价 ≤ 规定代价的画法 → ins ≤ min 放行代价；
- 最优画法分解出的 (路径, c) 是模型可行解（§2）→ min 放行代价 ≤ ins。
（模型是可实现集的超集，oracle 是真值判据；二者夹逼出精确值。）

**裁决循环**：求解 → oracle → 平面则放行；非平面则加入 no-good 子句
（精确剔除当前 (u, sel, c) 指派，不影响其他解）后重解。循环至「放行」或
「模型穷尽（该代价下无可行解，更无可实现解）」。循环次数有确定性计数上限
`max_nogood`，超限如实降级。

**正确性不依赖任何手工拓扑约束集**：即使 ILP 漏掉某些可实现配置（完整性缺口）
或放行不可能配置（可满足性超集），oracle 的双向定理保证最终输出仍精确——
这是把「可实现性判定 NP-hard」这一已知陷阱整体外包给平面性 oracle 的设计。

**贪心逐边插入 UB（oil 失败时的诚实兜底）**：初始 UB 插入若未在 `max_nogood`
内收敛（nogood-cap）或三角化失败，`len(F)` **不是恒真上界**（K7 反例：
F=6 < cr=9），不可作参考值。改为 `_greedy_insert_ub`：当前平面化画法 P
（初始 = U 嵌入）逐条插入 F——每步取 P 的平面嵌入三角化（含口袋拆分），
对偶图 0/1-Dijkstra 求含两端点三角形间的最少交叉路径，单边面路径插入
可实现（经典定理），交叉点细分 P 后重嵌。叶顶点（度 1，口袋为 2-圈）
继承邻居三角形集合——即 cr 保持定理的「叶子放进邻居关联面 0 交叉重连」。
全部插完后对最终平面化图做平面性终验；任何一步失败如实返回上层兜底。
产出的 UB 恒真且带 witness（每条 F 边的交叉边序列），非最优如实
proven=False。

## 5. 全局算法与证书语义

```
cr(G) 的计算：
1. 安全缩减 → 核族；
2. 每核：可平面 → 0（witness = 平面性判定）；
3. 否则 UB = 贪心极大可平面子图 + OIL 同时最优插入（oracle 验证）；
   LB = ⌈z*/2⌉（§6）；
   若 LB ≥ UB → proven（LB/UB 双向夹逼，无需枚举）；
   否则 B&B：对每个 |F| ≤ 2·UB−2 候选：
     G−F 可平面 + 2-连通 + 全嵌入枚举 → 决策「存在代价 ≤ UB−1 的可实现解」
     （oracle 裁决）；不可行 → 剪掉；可行 → 提取新 UB。
4. 覆盖完备（候选与嵌入均未触 cap）⇒ cr = UB 为数学证明；
   触 cap ⇒ proven 仅当 LB ≥ UB，否则 proven_optimal=false + gap=UB−LB。
```

**证书语义（严谨措辞）**：`proven_optimal=true` 表示 cr = UB 相对 §0-§5
定义的模型类（good-drawing 口径、缩减后核族、B&B 覆盖的可平面子图 × 全嵌入
族）成立；它不虚称全体指标集或任意画法空间的最优性。`gap = UB − LB`
在未证明时如实标注。`UB`（crossing_number）来自 oracle 验证的真实画法计数，
无条件为真。

## 6. 下界（全局有效）

任何画法中每个 Kuratowski 子图（K₅ / K₃,₃ 细分）内部必有交叉 → 每个子图
至少一条边被交叉。贪心抽取边不相交 Kuratowski 反例（`check_planarity`
counterexample 循环）后解 z-ILP：min Σ z_g s.t. 每个子图 Σ_{g∈K} z_g ≥ 1。
则 min 被标边数 ≤ 被交叉边数 ≤ 2·交叉数，故

> LB = ⌈z*/2⌉ ≤ cr(G)。

LB 与 UB 相等时无论枚举覆盖如何都可证最优（K5=1、K3,3=1 即此路径）。

## 7. 规律性的可计算定义（regularity.py）

「规律性」全部为**可计算、可复算**的数学量，无肉眼判断：

1. **结构检测**：cycle = 连通且全度数 2；chain = 连通、度 ≤2 且恰 2 个度 1；
   其余 general。
2. **环图正多边形偏差 D_poly ∈ [0,1)**：画出的 k 个中心点 p_i，质心 c，
   半径 r_i=|p_i−c|，相邻极角差 δ_i。radial_cv = std(r)/mean(r)，
   angular_cv = std(δ)/mean(δ)，**D_poly = 1 − exp(−(radial_cv + angular_cv))**。
   两 CV 全零 ⇔ D_poly=0（完美正 k 边形）。指标跑在**交付坐标**上，
   槽位量化取 2px（24px 粗量化会扭曲正多边形、抬高 CV——实测教训）。
3. **链图直线度 S_straight ∈ [0,1]**：链序相邻段夹角余量 (cosα+1)/2 的
   平均；完全共线 = 1，随机折线 ≈ 0.5。
4. **对称轴对齐度 A_sym ∈ [0,1]**：候选轴 = 节点 x 坐标与其两两中点
   （24px 槽位容差）；对每轴统计镜像伙伴命中率（同 y 且 x' = 2c−x ± 24），
   取最大。

结构检测决定**主导指标**（cycle→D_poly、chain→S_straight、general→A_sym），
全部指标照算照报、不做隐藏。

## 8. 槽位离散化放置（placement.py）

- **cycle**：正 k 边形槽位（角度均分 i·2π/k，2px 量化）。环序指派下环边
  全部落在凸包上 → 交叉按构造为 0；D_poly 按构造 ≈ 量化误差。构造法，
  无需求解器。**诚实边界**：这是槽位模型类内的构造最优，不是全排列
  最优性证明。
- **chain**：共线等距槽位（S_straight 按构造 = 1）。相邻边中心线段重叠
  由下游布线层以弧线消解，中心口径指标不受影响。
- **general**：分层行槽位 + CP-SAT。硬约束：行内净距 ≥ min_gap；跨行边在
  中间行处对无关框的插值 x 距框缘 ≥ CLEARANCE=17px（含 1px 余量；
  插值系数 t ∈ {1/2,1/3,2/3,1/4,3/4} 精确线性化，其余保守双端约束）；
  viewBox 内。目标：min 60·Σ交叉 + Σ|Δx|（与 auto-v2 定位目标同构）。
  num_workers=1 + seed 42，无墙钟时限（时限随负载漂移破坏确定性）。
  交付后由调用方跑 metrics/check 硬门复核，任何违例回退 auto-v2——
  本层绝不带伤交付。

## 9. 测试与真值出处

`tests/test_crossing_exact.py`：
- K5=1、K3,3=1（Kuratowski）；**K6=3**（Guy 1960 公式 cr(K_p)=¼⌊p/2⌋⌊(p−1)/2⌋
  ⌊(p−2)/2⌋⌊(p−3)/2⌋ 给出 p=5,6,7 → 1,3,9；Saaty 1964 证明该公式对 p≤10
  给出最优——故 K6=3、K7=9 是**已证明真值**，不是猜想；
  en.wikipedia.org/wiki/Crossing_number_(graph_theory) §Complete graphs）；
  **Petersen=2**（Wikipedia "Petersen graph" §Embeddings 原文：
  "The Petersen graph has crossing number 2"；并明示五角星画法的 5 处交叉
  不是最优画法）。**勘误（2026-11-05 验收打回核查）**：两个常见误读都不是
  真值——「Petersen=5」是五角星 naive 画法的交叉数；「K6=15」是 K6 的
  **边数**（C(6,2)=15），与交叉数无关。本文与实现取文献真值 2 / 3。
- **验收复跑环境纪律**：任何「proven/lb/coverage」证据必须同时声明解释器
  版本与 ortools 可用性。**无 ortools 时输出 proven=False、lb=0、
  coverage=partial 是 §5 的诚实降级特征**（测试 D 节专门验证其如实标注），
  不是 soundness 缺陷——2026-11-05 验收打回所引 evidence（全线 proven=False、
  lb=0、coverage=partial）逐字吻合该降级特征，即产自 ortools 不可用的环境。
  另注意：降级路径的 crossing_number 是启发式界（核心数回退 len(F)），
  恰在 Petersen/K6 上与真值重合属巧合，不构成「UB 恒真」证据。
- 随机图（5-7 节点）与独立 brute-force（≤2 交叉对全枚举 + 路径级平面化
  判定）逐图对照。
- 确定性：同图两次运行 JSON 逐字节一致。
- 降级：屏蔽 ortools 后 proven=False、coverage=partial（如实标注）。
- K3,3 细分图 = 1（homeomorphism invariance）。

`tests/test_placement.py`：cycle 交叉 0 + 偏差 ≤0.05；chain 直线度 =1；
general CP-SAT OPTIMAL + 确定性 + 行内净距复核。
