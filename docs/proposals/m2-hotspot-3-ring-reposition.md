# M2 优化提案 3/3：`ring_reposition`（环单节点去交叉重定位）

状态：提案（M1-B 前置交付物，未动手改；供 M2 拍板）。
证据基准：REPORT §10.3 聚合表；代码位 `stdraw/layout_auto.py:_ring_reposition`
（触发条件：engine=ring-construct 且选中环带弦交叉）。

## 现状证据

- 37 图聚合：`ring_reposition` 104,211 ms = **13.8%**，第三大段。
- 成本结构：每个「降级 1 环点」候选 × 旋转阶梯（REPOSITION_ROT_DEG）各跑一次
  **完整 delivery-chain probe + 硬门评估**（`_reposition_gate_eval`），
  直到第一个合格旋转为止；无候选时全阶梯扫完才返回 None。
- 语义约束（不动）：采纳门 = 双交叉口径全 0 + 全部硬门通过，严格
  zero-crossing-or-nothing——提案不得改语义，只省无效扫描。

## 改法（两步）

1. **弦代理预筛（返修后口径，2026-11-21 独立复核纠偏）**：候选按弦交叉数
   升序已排序；采纳目标 = 交叉 0。**可容许剪枝的方向性要求**：跳过条件
   「代理 ≥ 当前交付交叉对数 ⇒ 该候选不可能更优」只有当代理是**下界**
   （代理 ≤ 真值，never overcounts）时才安全——此时 代理 ≥ 当前值(≥1)
   ⇒ 真值 ≥ 代理 ≥ 1 > 0 ⇒ 不可能达 0，跳过不丢真值更低的候选。
   **现状的弦代理是过计数器（上游注释明言可能高估，真值 ≤ 代理）——
   过计数器配该跳过条件不安全**（代理 ≥ 当前 ⇒ 真值可能 < 当前，
   剪枝会砍掉可能达 0 的候选）。二选一，实现前拍板：
   a) 换/改造成真正的下界代理，并用单测钉死「代理 ≤ 真值（全候选集
      抽验）」后再启用剪枝；
   b) 放弃代理预筛，改为对全量重算做预算裁剪（不改采纳语义）。
   在 (a) 的单测落地前，本提案的剪枝步**不得实现**。
2. **旋转对称去重**：正 (k−1) 边形拟合的环画法对整圈旋转不变（槽位重标），
   REPOSITION_ROT_DEG 阶梯可按 k−1 阶旋转对称归并成代表元 + 规范偏移，
   评估次数 ~ 除以 (k−1)。需证明旋转阶梯的碰撞地形（InfeasibleRing）随
   对称等价——用环语料字节 sweep 验证，不等价就回退只留第 1 步。

## 预期收益

- 环类图段内 40–60%（无效旋转阶梯的 probe 占大头；预筛直接砍掉
  「不可能达标」的候选整段扫描）。聚合墙钟估 −3~6%。
- 触发面窄（仅弦交叉环图）：对已达标零交叉图是 no-op，无收益无风险。

## 确定性影响评估

- **低风险**：两步都是纯枚举削减，采纳门与平局键不变；字节等价性由
  「可容许剪枝 + 对称归并」论证，验证 = 环语料双腿逐字节 sweep
  （ortho 铁门 + auto 硬门照跑）。若对称论证实测不成立，仅保留第 1 步
  （该步无对称假设，字节等价最容易证）。
