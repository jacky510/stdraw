## 0. 设计原则(一句话)

工程制图身份:浅色 = 硫酸纸+点阵+墨线,深色 = 午夜墨(微蓝底)+中性钢灰容器;
**琥珀/天蓝极性墨水是画面上唯二的彩色**;证书 = 工程图签(直角标题栏),卡片 = 圆角 14。

要修的病灶(现状):琥珀色卡片(`#fffbeb`+`#f59e0b` 边)与 R 琥珀线(`#d97706`)同色相,
节点容器与边语义无层级;深色 slate 无身份。

## 4. 渲染层改动清单(超出纯 token 的部分)

1. **卡片圆角 14**:render.py 卡片 `<rect rx>`;锚点几何不受影响(锚点在边框直段,圆角只改角部)。
2. **画布网格**:浅色点阵 pattern / 深色线网格 pattern(SVG `<defs><pattern>`;viewer 用 CSS)。
3. **证书面板改图签式**:表格式布局(GRADE/GATES/CROSSINGS/PRESS/CLEAR/CV/MODE 六行两列)+
   直角外框 + 印章式 GRADE;工具栏/按钮沿用新 token。
4. **3D 浅色舞台**:render3d.py 增加 light 参数组(§3.1);深色路径字节不动。
5. **viewer/themes.js**:由 themes.py 重新生成(既有 drift gate 自动把关)。
6. 字体:标签 system-ui 12.5px/600;数值行 ui-monospace 10.5px(浅深同)。

## 5. 落地纪律(与仓库既有规则对齐)

- themes.py 注释明言 **light 层字节冻结**:本规格更换浅色 = 一次**有声明的主版本基线更新**
  (默认路径 21 图全量 sweep + 版本收口卡),不可作为普通改动混入其他卡。
- 3D 深色路径是现行产物:改完 2D 后 demo-3d 重渲染仅当输出字节变化(浅色新增会导致 3D demo
  增加 light 切换,深色渲染结果应字节不变——列入验收)。
- 建议实施卡序:①token 表落 themes.py(+drift gate 再生成)→ ②render.py 圆角/网格/图签 →
  ③render3d.py 浅色舞台 → ④demos 重渲染 + 截图更新 → ⑤版本收口(0.8.x 设计卡)。
- 验收:19 图语料浅色 sweep 全绿 + 双跑字节一致;深色 3D 输出与改前字节一致;RED 探针不需要
  (纯视觉层,不改门语义)。
