怎么拖（30 秒版）

  1. 节点：直接拖卡片到你觉得好看的位置。
  2. 边样式：双击一条边，循环切换 auto → straight → arc → free；free 后沿边拖动可插入折点手柄（每边最多 3 个），拖折点即钉住该边。
  3. 边锚点：鼠标悬停在某张卡片上会显示它的 16 个标准锚点（n/s/e/w、四角、黄金分割点等）；点击一个可见锚点，就把它指定给最近那条连边的端点（形如 n / se / g1）。同侧多条边的锚点想怎么分组就怎么点。
  4. 导出：拖完后点页面工具栏的 Export layout，浏览器会下载一个 JSON，把它改名成 <图名>-jacky.json（图名见下面每张卡的编号）。
  5. 都不满意？照样导出并注明「均不满意」——如实标注的负样本同样有价值（协议 §3）。

拖拽前初稿（<图名>-draft.json）已由准备卡预存在 benchmarks/manual/jacky-batch2/，你不需要动它。
